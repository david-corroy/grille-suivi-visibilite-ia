# Grille de suivi de visibilité IA — template gratuit

**Le tableau de bord mensuel pour suivre si ChatGPT, Perplexity et Gemini citent votre entreprise** — 3 indicateurs, 30 minutes par mois, aucun outil payant. Par [Bernard David Corroy](https://www.david-corroy.com/), consultant SEO & GEO.

## Les 3 indicateurs

| Indicateur | Question à laquelle il répond | Calcul |
|---|---|---|
| **Taux de citation** | Sur combien de mes questions l'IA me nomme-t-elle ? | citations / questions posées |
| **Exactitude** | Ce qu'elle dit de moi est-il juste ? | affirmations justes / total |
| **Part de voix** | Quel est mon poids face aux concurrents cités ? | mes citations / citations totales |

## La grille (colonne par colonne)

Le fichier [`grille-suivi-visibilite-ia.csv`](./grille-suivi-visibilite-ia.csv) s'ouvre dans Excel, Google Sheets ou Numbers :

| Colonne | Contenu |
|---|---|
| Mois | avril 2026, mai 2026… |
| Questions posées | le nombre de questions de votre panel testées ce mois-ci |
| Citations | combien de fois vous avez été nommé |
| Taux de citation | citations / questions (en %) |
| Exactitude | % d'affirmations justes quand l'IA parle de vous |
| Part de voix | votre % face aux concurrents cités |
| Alertes & action du mois | erreur nouvelle, concurrent qui monte — et UNE action décidée |

## Comment l'utiliser (le rituel mensuel)

1. **Constituez votre panel de questions** une fois pour toutes — les questions que VOS clients posent aux IA : [générer son panel de prompts acheteur](https://www.david-corroy.com/prompts-geo/panel-prompts-acheteur/)
2. **Chaque mois, même jour** : posez les questions du panel aux IA (conversations séparées — [pourquoi c'est crucial](https://www.david-corroy.com/prompts-geo/test-visibilite-ia/))
3. **Remplissez la ligne du mois** — à la main, ou avec [le prompt bilan qui la remplit pour vous](https://www.david-corroy.com/prompts-geo/grille-suivi-mensuel/)
4. **Décidez UNE action** pour le mois suivant. Pas cinq. Une.

## Règles d'honnêteté

- Un mois de données ne prouve rien : les IA varient d'une réponse à l'autre. **La tendance sur 3 mois est le signal**, pas la ligne isolée.
- Testez toujours depuis une session **non connectée** à vos conversations habituelles — sinon l'IA vous « connaît » et le test est faussé.
- Si votre part de voix monte mais vos demandes clients ne bougent pas après 6 mois, changez de questions : vous mesurez peut-être des questions que personne ne pose.
